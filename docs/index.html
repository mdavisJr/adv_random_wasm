adv-random

Random numbers, passwords and strings that follow rules, for JavaScript and TypeScript, in Node and in browsers.

npm install adv-random
npm GitHub Documentation The Rust crate, adv_random

Every example below runs in your browser with the package from npm. Rules like no duplicates, odd and even counts or at least 2 digits are given as settings, instead of being code you write, test and keep fair yourself.

Counts in any order

5 numbers from 1 to 39 where 4 come from one third of the numbers, 1 from another third, and none from the third that is left.

Loading...
Settings.builder(5)
    .range(1, 39)
    .noDuplicates()
    .rule(NumberPool.new().spread([4, 1, 0]).over(range(1, 13)).over(range(14, 26)).over(range(27, 39)))
    .build()
    .generate()
    .numbers();
